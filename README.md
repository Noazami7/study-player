# 字幕プレイヤー

スマホの中にある動画を、字幕・日本語訳・単語の意味を追いながら見るためのページ。
今の行に色が付いて自動でスクロールし、行をタップするとその行から再生する。「1行ずつ」にすると行の終わりで止まる。
「コピー」で今の行の英語と日本語訳を 2 行でコピーする。解説の付いた行には、単語の意味の下に解説が出る（「解説」で出し入れする）。

このリポジトリにあるのはページのプログラムだけで、動画も字幕も含まない。
動画（.mp4）と字幕データ（.json）は端末の中に置き、ページから選んで読み込む。どちらもネットには送らない。

## 使い方（iPhone）

1. 動画と字幕データを「ファイル」アプリの「このiPhone内」に入れておく
2. Safari でこのページを開き、共有メニューから「ホーム画面に追加」する
3. ホーム画面のアイコンから開き、「字幕データを追加」で .json を選ぶ（1 本につき最初の 1 回だけ）
4. 一覧の題名をタップし、「動画を選ぶ」→「ファイルを選択」から .mp4 を選ぶ

一度開いた後は、圏外でもホーム画面のアイコンから開ける。
Safari で追加した字幕データは、ホーム画面のアプリからは見えない（保存場所が分かれている）。
同じ動画の字幕データ（解説を足した版など）を「字幕データを追加」で読み込み直すと、前のものと置き換わる。前回の位置は残る。

## 画面の操作

縦持ちでは操作ボタンが画面の下端に並ぶ。よく押す「◀ 前」「↻ もう一度」「次 ▶」が一番下の段で、その上の段が
「一覧」「1行ずつ」速度（「1.0x」）「日本語」「単語」「解説」「コピー」。横持ちでは左に動画と操作ボタン、右に字幕が並ぶ。

- **コピー**: 色の付いた今の行を、英語と日本語訳の 2 行でコピーする（訳の無い行は英語だけ）。コピーしたら画面に「コピーしました」と出る。
  押した時だけコピーし、再生に合わせて勝手にはコピーしない
- **解説**: 解説の表示を出し入れする。「日本語」「単語」と同じく、次に開いた時も前の設定のまま。
  解説の付いた行が無い字幕データでは、このボタンは出ない
- **一覧**: 一覧に戻る。選んだ動画は外れるので、続きを見る時はもう一度選ぶ（最後に見ていた位置から「続きから」で再開できる）。
  「◀ 前」のすぐ上にあるので、動画を選んでいる時は押すと戻ってよいかを確かめる（再生中なら、確かめている間は動画を止め、キャンセルすると再生に戻る）
- 動画を選んだ時に出る「前回は 〜 まで見ました。」の案内は、「続きから」を押すか、行のタップ・「◀ 前」「↻ もう一度」「次 ▶」で
  見始めると消える。動画の ▶ で見始めた時は消えないので、うっかり頭から再生しても、この画面を開いている間は「続きから」で
  前回の位置へ戻れる。「続きから」を押さずに一覧へ戻ったりアプリを閉じたり（裏に回している間に閉じられた時も）すると、
  前回の位置は ▶ で見た所に置き換わる（そこが始まりから 5 秒以内なら「続きから」は出ない）
- 指で字幕をスクロールすると今の行を追わなくなる。「今の行へ ↓」で戻る

## 字幕データの形式

```json
{
  "format": "study-player/1",
  "id": "動画ごとに一意な文字列",
  "title": "一覧に出す題名",
  "video": "対応する動画のファイル名",
  "duration": 521.3,
  "lang": "en",
  "lead": "ページの先頭に出す説明",
  "cues": [
    { "s": 1.2, "e": 3.4, "t": "本文", "ja": "日本語訳", "g": [["見出し語", "品詞", "意味"]],
      "u": [[0, 5]], "alt": "別の聞き取り", "x": ["解説 1", "解説 2"] }
  ]
}
```

- `s` / `e`: 行の開始・終了（秒）
- `u`: 本文のうち聞き取りが不確かな文字の範囲（点線で示す）。無くてよい
- `alt`: 別の方式での聞き取り。無くてよい
- `x`: 解説。表示する順に並べた文字列の配列で、1 項目を 1 段にして単語の意味の下に出す。無くてよい
- `id` が同じ字幕データを追加すると、前のものと置き換わる
