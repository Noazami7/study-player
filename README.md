# 字幕プレイヤー

スマホの中にある動画を、字幕・日本語訳・単語の意味を追いながら見るためのページ。
今の行に色が付いて自動でスクロールし、行をタップするとその行から再生する。「1行ずつ」にすると行の終わりで止まる。

このリポジトリにあるのはページのプログラムだけで、動画も字幕も含まない。
動画（.mp4）と字幕データ（.json）は端末の中に置き、ページから選んで読み込む。どちらもネットには送らない。

## 使い方（iPhone）

1. 動画と字幕データを「ファイル」アプリの「このiPhone内」に入れておく
2. Safari でこのページを開き、共有メニューから「ホーム画面に追加」する
3. ホーム画面のアイコンから開き、「字幕データを追加」で .json を選ぶ（1 本につき最初の 1 回だけ）
4. 一覧の題名をタップし、「動画を選ぶ」→「ファイルを選択」から .mp4 を選ぶ

一度開いた後は、圏外でもホーム画面のアイコンから開ける。
Safari で追加した字幕データは、ホーム画面のアプリからは見えない（保存場所が分かれている）。

## 字幕データの形式

```json
{
  "format": "study-player/1",
  "id": "動画ごとに一意な文字列",
  "title": "一覧に出す題名",
  "video": "対応する動画のファイル名",
  "duration": 521.3,
  "lang": "en",
  "lead": "ページの先頭に出す説明",
  "cues": [
    { "s": 1.2, "e": 3.4, "t": "本文", "ja": "日本語訳", "g": [["見出し語", "品詞", "意味"]],
      "u": [[0, 5]], "alt": "別の聞き取り" }
  ]
}
```

- `s` / `e`: 行の開始・終了（秒）
- `u`: 本文のうち聞き取りが不確かな文字の範囲（点線で示す）。無くてよい
- `alt`: 別の方式での聞き取り。無くてよい
